# 安路 FPGA 实时手势视觉互动系统

基于安路 PH1P35/HX1P35A 开发板实现的单芯片实时视觉互动作品。

系统从 MIPI 摄像头采集开始，在 FPGA 内完成 ISP、边缘检测、手部识别、指尖跟踪、
刀锋交互、游戏逻辑和画面叠加，最终以 1280×720@60 输出到 HDMI 显示器。
整套体验不依赖外部电脑、通用操作系统或独立 AI 加速设备，上电后即可运行。

| 视觉能力 | ISP、AWB、全分辨率边缘检测、手部识别、指尖跟踪 |

## 当前已完成的功能

### 1. 完整的 MIPI 到 HDMI 实时视觉链路

摄像头图像经过 MIPI D-PHY 接收、RAW10 解包、去马赛克、自动白平衡、图像处理和
DDR2 帧缓存后送入 HDMI 显示。整条链路在 1280×720@60 下运行，为手势识别和游戏
提供稳定、低延迟的实时画面。

### 2. RAW 与边缘检测双视图

- `RAW`：直接显示摄像头彩色画面。
- `EDGE`：显示 FPGA 实时计算的全分辨率 Sobel 梯度灰度图。
- 两种视图可通过板载按键即时切换，便于演示视觉算法效果。
- 边缘门限支持拨码开关和串口在线调节。

### 3. FPGA 内的实时手部识别与跟踪

手部识别完全在 FPGA 数据流中完成，不依赖外部处理器。系统结合肤色、运动信息、
时域投票和块级占比门抑制背景噪声，并对掩码、手部区域和指尖结果进行稳定处理。

在游戏模式中默认只显示白色指尖点，画面干净；需要调试或展示算法时，可切换到
掩码视图，观察肤色掩码、黄色准星和指尖位置。

### 4. 平滑的隔空刀锋交互

指尖位置被映射为屏幕刀锋，玩家只需在摄像头前挥动手指即可完成切割。

- 白色指尖点已放大，远距离观察更清晰。
- 刀锋轨迹使用历史点插值，快速挥动也不会漏掉水果。
- 失锁后重新锁定会从当前指尖位置重新建立轨迹，不跨屏补放旧轨迹。
- 游戏画面默认隐藏掩码和黄色准星，避免调试元素干扰正式演示。

### 5. 切水果游戏

- 水果从画面下方抛出，形成抛物线运动。
- 按挥动方向生成上下半片或左右半片。
- 命中水果后显示黄色粒子效果。
- 炸弹使用独立造型和橙红色爆散粒子。
- 分数支持负数，并显示两位有符号 BCD 分数。
- 取消生命值设定，漏掉水果只扣分，不会立即结束游戏。

### 6. 手势接果篮游戏

- 水果和炸弹从屏幕顶端落下。
- 指尖位置控制底部果篮左右移动。
- 下落速度会随游戏时间逐步提高。
- 接住水果得分，漏掉水果扣分，接住炸弹受到高额扣分。
- 与切水果共用同一套手势输入、视觉链路和显示系统。

### 7. 完整的视觉反馈与现场演示能力

- 水果、炸弹、半片、粒子和果篮均由 FPGA 直接绘制。
- OSD 显示作品 Logo、算法状态、分数和运行信息。
- 板载 LED 显示心跳、算法状态、游戏状态和按键事件。
- 串口输出帧计数、曝光、识别统计和链路状态，便于现场诊断。
- 运行模式、边缘门限和识别视图均支持串口在线配置。

## 操作方式

### 快速开始

1. 连接 MIPI 摄像头和 HDMI 显示器。
2. 给开发板上电，或将交付的 bitstream 烧录到 FPGA。
3. 屏幕出现实时摄像头画面后即可开始体验。

### 板载按键

| 按键 | 作用 |
|---|---|
| `KEY1` | 在彩色画面 `RAW` 与边缘检测画面 `EDGE` 之间切换 |
| `KEY2` | 降低摄像头曝光目标值 |
| `KEY3` | 提高摄像头曝光目标值 |
| `KEY4` | 循环切换：普通画面 → 切水果 → 接果篮 → 普通画面 |

进入任一游戏时，系统自动开启手势识别并切换到只显示白色指尖点的干净游戏视图。

### 切水果玩法

1. 短按 `KEY4`，进入切水果。
2. 将手伸入摄像头视野，等待白色指尖点稳定出现。
3. 移动或挥动手指，用屏幕上的刀锋轨迹切中水果。
4. 继续短按 `KEY4` 进入接果篮，或再短按一次退出游戏。

计分规则：

| 事件 | 分数变化 |
|---|---:|
| 切中水果 | `+1` |
| 漏掉水果 | `-1` |
| 切中炸弹 | `-5` |
| 漏掉炸弹 | 不扣分 |

### 接果篮玩法

1. 在游戏中短按 `KEY4`，进入接果篮。
2. 左右移动手部，底部果篮会跟随指尖水平位置移动。
3. 接住水果得分，避开炸弹。
4. 短按 `KEY4` 返回普通画面。

计分规则：

| 事件 | 分数变化 |
|---|---:|
| 接住水果 | `+1` |
| 漏掉水果 | `-1` |
| 接住炸弹 | `-5` |
| 漏掉炸弹 | 不扣分 |

### 现场调试视图

正常游戏只显示白色指尖点。使用串口发送以下命令可切换显示模式：

```text
W 08 0001    # 显示肤色掩码、黄色准星和白色指尖点
W 08 0006    # 恢复干净游戏视图
W 08 0000    # 关闭识别叠加
```

## 项目优点

### 1. 真正的单芯片端到端实现

从摄像头采集、视觉识别、交互判定到游戏画面输出，全部由同一片 FPGA 完成。
作品不依赖 PC 端程序，也不需要摄像头数据离开开发板，完整展示了一个可独立运行的
嵌入式视觉系统。

### 2. 实时性来自硬件数据流

视觉处理采用同步像素流和并行硬件计算，而不是逐帧调用软件算法。边缘检测、掩码
处理、指尖跟踪和游戏碰撞均跟随视频流水线实时运行，适合低延迟的现场互动。

### 3. 视觉识别与游戏形成完整闭环

系统不仅输出识别结果，还把结果直接转化为刀锋、果篮、得分、粒子和炸弹反馈。
裁判看到的不只是算法演示，而是一套“看见动作、理解位置、即时反馈”的完整交互作品。

### 4. 两套玩法复用同一套硬件能力

切水果强调轨迹、方向和粒子反馈，接果篮强调位置映射、物体下落和判定。两种玩法
复用同一套摄像头链路、手势识别、参数系统和画面合成通路，体现了设计的复用性和扩展性。

### 5. 面向现场展示的稳定性设计

- 肤色、运动和空间密度共同筛选手部区域。
- 时域投票和块级占比门抑制背景及指缝噪声。
- 轨迹插值提升快速挥动时的命中连续性。
- 跨时钟域数据和模式提交采用握手与帧同步，避免切换时画面撕裂。
- 正式游戏隐藏调试叠加，只保留清晰的白色指尖点。

### 6. 资源与时序结果具备交付质量

工程已在目标器件上完成综合、布局布线和 bitgen：

| 资源/指标 | 结果 |
|---|---:|
| slices | `18678 / 21216`（88.04%） |
| LUT6 | `17358 / 21216`（81.82%） |
| 触发器 | `16442 / 42432`（38.75%） |
| ERAM | `80 / 108`（74.07%） |
| DSP | `8 / 40`（20.00%） |
| final Setup WNS | `+550 ps` |
| final Hold WNS | `+20 ps` |

最终结果 0 时序违例，可在目标开发板上直接运行。

### 7. 模块化设计便于继续扩展

系统将视频输入、识别、参数控制、游戏层和画面叠加拆分为独立模块，并保留统一的
参数与观测接口。后续可以继续加入新的手势游戏、视觉效果或识别策略，而不必重做整条
MIPI、DDR2 和 HDMI 链路。

## 系统结构

```text
MIPI 摄像头
    │
    ▼
FPGA 图像处理
    ├── RAW 彩色画面 ───────────────┐
    ├── Sobel 边缘检测 ─────────────┤
    └── 手部识别与指尖跟踪 ─┐       │
                            │       ▼
                            │   DDR2 帧缓存
                            │       │
                            │       ▼
                            └── 游戏逻辑与画面叠加
                                    │
                                    ▼
                              HDMI 1280×720@60
```

## 编译与交付

TangDynasty 工程入口：

```text
td_project/camera_to_dsi_display.al
```

首次构建或新工作区初始化：

```powershell
pwsh -NoProfile -File tools/new_worktree_runs.ps1
```

执行综合、布局布线和 bitgen：

```powershell
pwsh -NoProfile -File tools/build_td.ps1
```

构建脚本会输出资源、时序和 bitstream 路径，并自动归档普通版与压缩版 bit：

```text
td_project/camera_to_dsi_display_Runs/phy_1/camera_to_dsi_display.bit
td_project/camera_to_dsi_display_Runs/phy_1/camera_to_dsi_display_compress.bit
```
